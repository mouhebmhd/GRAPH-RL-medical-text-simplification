Health literacy profiles

Each spider graph draws one profile. The value at each axis is the degree (%) of that dimension: literacy, digital preference, adaptability, topic variance and spiritual anchoring (100% = spiritual-first on). The suitability % is a judgement by the LLM, which is given each profile's description; it is indicative, not a verified metric. The profile only changes the readability target and the prompt; it never relaxes the safety check.
